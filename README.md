# NegocioApp

Aplicación de escritorio desarrollada en **C# con Windows Forms**, pensada para facilitar el registro de productos y la gestión de ventas en pequeños negocios.

## Funcionalidades

- Agregar productos con nombre, descripción, cantidad, precio y categoría.
- Visualizar los productos registrados en una tabla.
- Editar y eliminar productos.
- Generar un ticket con el detalle de los productos y sus subtotales.
- Calcular el total de la venta.
- Finalizar una compra e iniciar una nueva venta.

## Tecnologías utilizadas

- C#
- Windows Forms
- .NET
- Visual Studio

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir el archivo `NegocioApp.sln` con Visual Studio.
3. Esperar a que se cargue el proyecto.
4. Ejecutar la aplicación.

## Sobre el proyecto

NegocioApp es un proyecto personal realizado para poner en práctica conocimientos de programación, lógica y desarrollo de interfaces gráficas con C#.
